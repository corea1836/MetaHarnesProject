# 단편 웹툰 기획·글콘티

단편 웹툰은 8~12컷 안에 독자를 붙잡고, 하나의 감정 변화를 완성하고, 마지막 컷에서 여운이나 웃음을 남겨야 한다. 분량이 짧아 곁가지를 넣을 자리가 없다. 그래서 “무엇을 뺄지”가 “무엇을 넣을지”보다 중요하다.

## 1. 기획안

`_workspace/01_writer_concept.md`에 아래 구조로 쓴다.

```markdown
# {제목}

- **로그라인:** {한 문장. 누가, 무엇을 원하는데, 무엇이 막는가}
- **장르·톤:** {예: 일상 개그, 따뜻함 7 : 웃음 3}
- **독자가 느낄 한 가지:** {다 읽고 난 뒤의 감정 하나}
- **분량:** {그림 컷 N개 + 글자 카드 M개}

## 등장인물
| 이름 | 역할 | 성격 | 말투 | 외형 키워드 |
|------|------|------|------|------------|
(최대 3명. 외형 키워드는 디자이너가 설정집을 만들 실마리이므로 고유 표식 하나 이상)

## 장소
(1~2곳)

## 비트 시트
| 구간 | 컷 | 내용 |
|------|----|------|
| 훅 | 1~2 | |
| 전개 | 3~6 | |
| 반전·절정 | 7~9 | |
| 펀치·여운 | 10~12 | |
```

### 기획 원칙

- **첫 두 컷 안에 궁금증을 만든다.** 독자는 첫 화면에서 계속 볼지 정한다. 평범한 배경 소개로 시작하더라도 내레이션이나 이상한 디테일 하나로 질문을 던진다.
- **갈등은 하나만.** 짧은 분량에 갈등이 둘이면 둘 다 풀리지 않는다.
- **결말은 앞에서 심어 둔 것을 거둔다.** 반전이나 펀치라인은 앞 컷에 나온 소품·대사·습관을 다른 의미로 뒤집을 때 가장 잘 먹힌다. 갑자기 나온 정보로 끝내지 않는다.
- **인물은 세 명 이하.** 이야기 때문이기도 하지만, 인물이 많을수록 작화에서 얼굴과 옷이 섞여 일관성이 무너지기 때문이다.

## 2. 글콘티

기획안이 승인되면 `_workspace/02_writer_script.md`에 컷 단위로 쓴다. 연출가가 컷을 패널로 옮기므로 **한 컷 = 한 그림**이 되게 나눈다.

```markdown
# {제목} 글콘티

## S1. 편의점 앞 / 새벽 3시

### C1 (글자 카드)
- 카드: "편의점 고양이"

### C2
- 그림: 텅 빈 거리, 불 켜진 편의점 하나. 위에서 내려다본다.
- 내레이션: "새벽 세 시. 이 시간엔 손님이 거의 없다."

### C3
- 그림: 카운터에 턱을 괴고 조는 미나. 뒤로 유리문이 열리기 시작한다.
- 효과음: 딸랑
- 미나: "어서오세요~"
- 연출 메모: 다음 컷의 정체 공개 전에 긴 여백
```

- `그림:` 줄에는 독자가 **보는 것**을 쓴다. 인물의 생각이나 배경 설정 설명은 쓰지 않는다. 그릴 수 없는 정보이기 때문이다.
- 대사는 `이름: "대사"`, 속마음은 `이름(속마음): "…"`, 외침은 `이름(외침): "…"`, 화면 밖 목소리는 `이름(화면 밖): "…"`로 표시한다. 연출가가 말풍선 종류를 정하는 근거가 된다.
- `연출 메모:`는 선택이다. 여백·리빌·시선처럼 의도가 있을 때만 쓴다.

### 대사 원칙

- 한 말풍선에 40자 이하, 한 컷에 말풍선 세 개 이하. 웹툰 독자는 스크롤하며 읽으므로 긴 대사는 건너뛴다.
- 그림이 보여 주는 것을 대사로 반복하지 않는다. “비가 오네”는 비 오는 그림 옆에서 필요 없다.
- 설명 대사(“너도 알다시피 우리는 10년 지기잖아”)를 쓰지 않는다. 관계는 행동과 말투로 보여 준다.
- 인물마다 말투를 구분한다. 기획안 표의 말투를 끝까지 지킨다.
- 맞춤법과 띄어쓰기를 지킨다. 의도한 구어체(“뭐야아”)는 괜찮지만 오타는 아니어야 한다.

## 3. AI 작화를 고려한 각본

이 하네스는 이미지 모델로 그림을 만든다. 모델이 잘 못 그리는 것을 이야기의 핵심에 두면 재생성 비용만 늘고 결과도 나쁘다.

| 피할 것 | 이유 | 대신 |
|---------|------|------|
| 화면 속 글자가 중요한 장면(편지 내용, 간판, 메시지) | 이미지 모델은 한글을 정확히 그리지 못한다 | 내용을 말풍선(`electronic`)·내레이션·글자 카드로 전한다 |
| 4명 이상이 함께 나오는 컷 | 얼굴·옷이 섞인다 | 주요 인물만 앞에, 나머지는 뒷모습·실루엣 |
| 손이 핵심인 동작(손깍지, 악기, 카드 마술) | 손가락 결함이 잦다 | 결과(표정, 소리)로 보여 준다 |
| 같은 인물이 한 컷에 두 번(분신, 거울 대화) | 모델이 둘을 다르게 그린다 | 컷을 나눈다 |
| 정밀한 숫자·시계·지도 | 정확도가 낮다 | 내레이션으로 말한다 |

## 다시 호출될 때

- 이전 산출물(`01_writer_concept.md`, `02_writer_script.md`)을 먼저 읽는다.
- 편집자나 사용자의 피드백은 지적된 부분만 고친다. 고친 부분을 응답에 컷 번호로 나열한다. 연출가가 콘티의 어느 부분을 바꿔야 할지 판단하는 근거가 된다.
- 결말을 바꾸는 피드백이면 앞쪽 복선도 함께 손본다. 결말만 바꾸면 거둘 것 없는 복선이 남는다.
