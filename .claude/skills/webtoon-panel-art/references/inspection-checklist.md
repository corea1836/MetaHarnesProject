# 패널 검수 체크리스트

검수자(`panel-inspector`)는 패널 이미지, 그 패널의 콘티 항목, 설정집, 참조한 기준 시트를 **모두 직접 열어** 대조한다. 프롬프트 파일만 보고 판정하지 않는다. 프롬프트가 맞아도 결과는 다를 수 있다.

## 판정 기준

| 판정 | 기준 |
|------|------|
| **PASS** | 아래 필수 항목을 모두 통과했다. 권장 항목의 사소한 아쉬움은 `issues`에 적되 PASS로 둔다. |
| **FIX** | 필수 항목 중 **국소적인** 문제가 한두 개다. 구도는 맞고 일부만 고치면 된다(옷 색, 고유 표식, 표정, 작은 글자 흔적). |
| **REDO** | 구도·인물 수·장면이 콘티와 다르거나, 인물이 다른 사람으로 보이거나, 결함이 커서 편집으로 고칠 수 없다. |

애매하면 더 엄격한 쪽을 고른다. 검수에서 놓친 문제는 최종 합성본에서 발견되며, 그때 고치면 비용이 더 든다. 다만 같은 문제를 두고 버전을 거듭해도 나아지지 않으면(이전 판정의 `issues`와 같은 문제가 반복) 그 사실을 `issues`에 적어 오케스트레이터가 판단하게 한다.

## 필수 항목

1. **인물 일치**: 콘티의 `characters`에 있는 인물이 모두 있고, 없는 인물은 없다. 각 인물이 기준 시트와 같은 사람이다. 머리 길이·색·모양, 눈 색, **고유 표식**, 체형을 하나씩 대조한다.
2. **의상**: 콘티가 지정한 `outfit`(없으면 `default`)과 맞다.
3. **표정·동작**: `expression`과 `pose`, `visual_prompt`의 동작이 읽힌다.
4. **샷·앵글**: `shot`과 `angle`이 대체로 맞다. `close-up`인데 전신이 나왔다면 실패다.
5. **말풍선 자리**: `negative_space` 영역이 비교적 비어 있다. 그 자리에 얼굴이나 핵심 동작이 있으면 말풍선이 가리게 된다.
6. **글자 없음**: 글자·숫자·말풍선·서명·워터마크가 없다. 배경의 흐릿한 간판 형태는 읽히지 않으면 괜찮다.
7. **화풍**: 설정집 `style.anchor`와 화풍 기준 이미지의 선·채색·팔레트와 맞다.

## 권장 항목

- 손·손가락 결함(개수, 꺾임), 팔다리 연결
- 원근·비율의 큰 어긋남
- 앞뒤 컷과의 연속성: 같은 장면이면 조명·시간대·좌우 배치가 이어지는가. 앞뒤 컷 이미지가 있으면 함께 열어 본다.

## 출력 형식

최종 응답은 사용자에게 보내는 글이 아니라 오케스트레이터가 저장할 **데이터**다. 아래 JSON 하나만 코드 블록으로 반환한다.

```json
{
  "batch": 1,
  "round": 1,
  "results": [
    {
      "panel": "p03",
      "file": "_workspace/05_artist_panels/p03_v1.png",
      "verdict": "FIX",
      "score": 7,
      "checks": {
        "characters": "미나 일치. 단 왼쪽 눈 밑 점 누락",
        "outfit": "통과",
        "expression_pose": "통과",
        "shot_angle": "통과",
        "negative_space": "통과",
        "no_text": "통과",
        "style": "통과"
      },
      "issues": ["mina의 고유 표식(왼쪽 눈 밑 점) 누락"],
      "fix_prompt": "Add the small mole under Mina's left eye, matching reference image 2."
    }
  ]
}
```

- `score`: 0~10. 같은 패널의 여러 버전 중 무엇을 고를지 정할 때 쓴다.
- `fix_prompt`: FIX·REDO일 때 필수. 작화가 프롬프트에 그대로 붙일 수 있는 **영어** 지시로 쓴다. 문제를 다시 말하지 말고 원하는 결과를 쓴다(“remove X”보다 “plain wall behind her head”).
- PASS면 `fix_prompt`는 빈 문자열이다.
